PARAMETER QUICK REFERENCE
━━━━━━━━━━━━━━━━━━━━━━━━━
--obj PATH              OBJ file path (default: 3DModel_1/OBJ/3DModel.obj)
--texture PATH          Texture file (PNG/JPG). Optional. e.g., 3DModel/tex.png
--output PATH           Output file (default: 3DModel_1/model_rotation.gif)
--axis AXIS             Rotation axis. See AXIS FORMATS below
--frames N              Number of frames (default: 36) - higher = smoother
--fps N                 Playback speed (default: 10)


AXIS FORMATS
━━━━━━━━━━━━
Standard axes (single letter):
  --axis x              Rotate around X axis
  --axis y              Rotate around Y axis
  --axis z              Rotate around Z axis (DEFAULT)

Arbitrary vectors (automatically normalized):
  --axis 1,1,1          Diagonal through all axes (45° from each)
  --axis 1,0,0          Equivalent to --axis x
  --axis 1,1,0          45° between X and Y, no Z tilt
  --axis 0.7,0.5,0.5    Mostly X rotation with mixed Y and Z
  --axis 0,1,0.5        Mostly Y rotation, some Z tilt


AXIS VECTOR GUIDE
━━━━━━━━━━━━━━━━━
Vertical spin (like carousel):
  --axis 0,1,0          or  --axis y

Horizontal rotation (turntable):
  --axis 0,0,1          or  --axis z (DEFAULT)

Forward roll (like wheel):
  --axis 1,0,0          or  --axis x

Diagonal (show all 3D):
  --axis 1,1,1          Balanced 3D rotation

Mixed rotations:
  --axis 1,1,0          XY plane, 45° angle
  --axis 1,0,1          XZ plane, 45° angle
  --axis 0.5,1,0.5      Mostly Y, some X and Z
